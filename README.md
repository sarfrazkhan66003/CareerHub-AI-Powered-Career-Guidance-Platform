# 🚀 CareerHub – AI-Powered Career Guidance Platform

> **Find Your Path, Follow Your Passion** 🎯

CareerHub is an EdTech startup demo project focused on solving one of the biggest problems students face today — **career confusion**. This repository represents the **MVP (demo version)** of the CareerHub platform, designed to provide **structured, mentor-driven, and future AI-powered career guidance** for students.

---

## 🌟 Project Overview

Many students choose their career paths without clarity, proper guidance, or understanding of real-world job demand. CareerHub is built to bridge this gap by combining:

- 🎓 Student-focused career counseling  
- 🤝 Mentor-based guidance (college students & graduates)  
- 📊 Market-aware career insights  
- 🧠 Future AI-driven career assessments  

This project demonstrates the **core backend architecture, authentication system, and scalable structure** required to build a full-fledged career guidance platform.

---

## 🧠 Vision & Mission

### 🎯 Vision
To empower students with clarity, confidence, and correct career direction at the right time.

### 🚀 Mission
- Reduce career confusion after Class 8, 9, 10 & 12  
- Provide real mentorship instead of generic advice  
- Align student interests with market demand  
- Build India’s most trusted career guidance ecosystem

## 🛠️ Tech Stack

### 🔹 Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- Express Sessions
- Bcrypt (Password Security)

### 🔹 Frontend
- EJS (Embedded JavaScript Templates)
- EJS-Mate (Layouts)
- CSS & Static Assets

### 🔹 Tools & Libraries
- Body-Parser
- Method-Override
- CORS
- Session-based Authentication

## 🔐 Authentication Features

- ✅ Secure User Registration & Login
